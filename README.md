# Young and Dufe

> Ethical African Botanicals & Handcrafted Shea Butter

An ethical natural ingredients platform built with **Next.js 16 (App Router)**, **TypeScript**, and **Tailwind CSS**.

---

## ✨ Features

- **Cinematic Hero**: Autoplay loop video showcasing artisanal shea processing.
- **Dynamic Scrolled Navigation**: Seamless transition from transparent hero overlay to a fixed caramel-tan header bar with responsive navigation.
- **Interactive Counters**: Animated statistics for community engagement and sustainability metrics.
- **Product Architecture**: Full specifications, INCI tables, and sourcing pipelines for:
  - Handcrafted Shea Butter
  - Organic Virgin Coconut Oil
  - Cold-Pressed Baobab Oil
  - Traditional African Black Soap
- **Provenance & Traceability**: Dedicated batch-level traceability module and EUDR verification.
- **Complete Route Coverage**: 12 fully designed and tested screens across About, Products, Impact, FAQ, and Wholesale Contact.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router, Turbopack)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Typography**: Oswald, Outfit, and Bobby Jones Soft
- **Icons**: [Lucide React](https://lucide.dev/)

---

## 🚀 Getting Started

### 1. Install Dependencies

```bash
npm install
```

### 2. Run Local Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Production Build

```bash
npm run build
npm run start
```
